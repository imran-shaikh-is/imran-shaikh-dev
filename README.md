# Imran Shaikh — Portfolio

A responsive React + Vite portfolio website for showcasing Python/backend development and Generative AI/RAG projects.

## Run locally

1. Install Node.js (LTS).
2. Extract this project folder.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in the `dist/` folder.

## Personalize before publishing

Content (projects, skills, contact links) lives in `src/App.jsx`. Add your employment history there if you want an Experience section.

Review all project descriptions and technology tags to ensure they match your actual implementation before publishing.

## Deploy

You can deploy the project to Vercel or Netlify by importing the GitHub repository. Use `npm run build` as the build command and `dist` as the output directory.
